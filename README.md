# Xplorer

A Windows Explorer–style file manager for macOS (SwiftUI, macOS 13+).

Build & install: `./build.sh --install` → `~/Applications/Xplorer.app`

Shortcuts: Enter open · Backspace up · ⌥←/⌥→ back/forward · ⌘L type a path · ⌘F search ·
⌘C/⌘X/⌘V copy/cut/paste files · F2 rename · Delete trash · ⌘⇧N new folder · ⌘⇧C copy path ·
⌘⇧T Terminal here · ⌘⇧. hidden files · Space Quick Look · ⌘I / ⌥Enter Properties · ⌘T new tab · ⌥P preview pane · F5 refresh · Ctrl works like ⌘.
